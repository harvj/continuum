# v0.1.0 — Continuum Application Foundation

- One Rails/PostgreSQL service hosts Network, Library and Intelligence.
- Each landing page has a shared DM Sans identity, an accessible ordered
  navigation with the Auth home link, an empty main landmark and a viewport
  footer.
- Site Art's three stable identifiers resolve automatically from the verified
  shared publication snapshot. Missing artwork uses a neutral surface.
- Rails liveness, database readiness, a proposed systemd unit and a scoped
  infrastructure route support independent deployment.

This release contains no application content, user accounts, migration
importer, search, AI interface, or registered background artwork. Existing
Squarespace preservation tools remain available. Production deployment and
commissioning of Site Art automatic publication require separate authorization.
